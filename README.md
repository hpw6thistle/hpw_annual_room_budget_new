# 匿名展示靜態包

將 index.html、assets/、.nojekyll 放在網站根目錄。可部署至 GitHub Pages；GitHub 不會自動解壓 ZIP。沿用部署 workflow 時，替換網站檔案再推送 main。

先選館別／角色，在「密碼」欄輸入展示密碼，再按「登入->」。hotel1～hotel12、rsvn、finance 的初始預設均為 `hpw`。所有角色可在帳號抽屜修改自己的密碼；財務可管理全部 14 個入口。修改自己密碼後需重新登入；變更僅本分頁生效。升級只替換已知舊預設密碼，保留自訂密碼、預算、版本、損益、房間與設定。

rsvn／finance 登入後可在工作範圍自由切換12館；各館身份僅進入所屬館別，切換身份須重新登入。前端密碼可讀、可繞過，只能防誤入，不是正式登入或資料隔離。只能用匿名假資料，不用正式密碼、個資或財務資料。

財務可先進「財務初始設定」保存既有科目金額及稅額方式。按「匯出初始設定 Excel／範本」下載目前編輯內容；在 Excel 填寫後按「匯入初始設定 Excel」，檢查預覽、確認載入編輯區，再按「儲存初始設定」。同館別／年度、1–12月金額與所得稅方式一併處理，空白視為零，最多三位小數；不接受公式或其他範本。自動所得稅月份留空。匯入不會追改既有財務版本或來源。

各館／聯訂提交後才能另建財務草稿，新稿複製建立當時的初始設定。新設定預設1–12月手動稅額；自行選用自動模式時，計算欄位仍唯讀。提交鎖定不等於主管核准。客房收入 Excel 工具位於「Excel 直式預算表」同列；手機月份欄縮為72px。

已移除展示資料重設功能，更新不清除既有已儲存資料。新儲存區 hotel-budget-anonymous-entry-v2 不讀舊站內容。主管核定與實績匯入仍屬後續規劃。此包不能代替正式後端保存。

目前版本2.0.4，下一版2.0.5。

Windows原生區網主機另行交付；此公開匿名站仍是瀏覽器分頁展示，不提供正式共用資料庫、完整稽核或主機備份。
